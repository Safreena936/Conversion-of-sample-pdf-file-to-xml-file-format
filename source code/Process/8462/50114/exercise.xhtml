  11. Is it possible for a logarithm (of the form \(\log _{a}b\)) to give a negative result? If so, give an example and reasons.

    Yes. \(0< b< 1\Rightarrow \log _{a}\left (b\right )< 0,\ \text{when}\ a> 1\); e.g. \(\log _{2} \left (\dfrac{1}{4}\right )= - 2\).
